# H.XuanHui's Notes 

一些上班整理的說明文件 ver.obsidian，透過 Quartz v4 發佈為 GitHub Pages 上的技術知識庫。

👉 **線上版知識庫**：<https://hxuanhui.github.io/HXuanHui.github.io-CGM-/>

***

## 🌱 關於這個知識庫

- 主要記錄工作中遇到的問題、處理步驟與說明文件，方便之後快速查閱與複用。
- 使用 Obsidian 做日常筆記，透過 Quartz v4 將這些筆記轉成公開網站。
- 目標是把零散的技術經驗，整理成有脈絡、可連結且可持續演化的知識庫。

***

## 🧭 內容主題導覽

- **Database**
  - PostgreSQL：安裝、設定、日常維運、小坑紀錄。
  - Oracle：Instance / Tablespace 管理、備份、常見錯誤處理。
- **Development**
  - AutoUpdater：AutoUpdater.Net 整合與使用方式筆記。

也可以透過右側的互動式圖譜，從節點間的關聯來探索整個知識庫。
